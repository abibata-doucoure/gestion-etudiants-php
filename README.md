# 🎓 Gestion d'Étudiants - PHP/MySQL
Projet L3 IDA - Abidjan

Application web pour gérer les étudiants d'une filière.

### Fonctionnalités
- Ajout d'étudiant
- Affichage de la liste
- Base de données MySQL

### Technologies
PHP, MySQL, HTML, CSS

### Installation
1. Importer base.sql dans phpMyAdmin
2. Lancer avec XAMPP
